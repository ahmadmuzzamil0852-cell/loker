# 📦 Loker - Catalog Gudang Kerinci

Sistem manajemen dan katalog gudang untuk Kerinci yang dirancang untuk memudahkan pengelolaan inventori dan stok barang.

## 🎯 Deskripsi Proyek

**Loker** adalah aplikasi web yang dibangun dengan Laravel untuk membantu mengelola katalog produk dan inventori gudang Kerinci secara efisien dan terpusat.

## ✨ Fitur Utama

- 📋 Manajemen katalog produk
- 📊 Tracking inventori real-time
- 🏷️ Kategorisasi barang
- 🔍 Pencarian dan filter produk
- 📈 Laporan stok
- 👥 Manajemen pengguna

## 🛠️ Teknologi

- **Framework**: Laravel
- **Database**: MySQL/PostgreSQL
- **Frontend**: Blade Templates
- **Backend**: PHP

## 📋 Persyaratan Sistem

- PHP >= 8.0
- Composer
- Node.js & NPM
- Database (MySQL/PostgreSQL)
- Git
